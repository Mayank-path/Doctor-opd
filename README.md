# Doctor OPD SaaS

A new doctor-focused OPD management platform for Indian clinics.

## Planned architecture

- Mobile: Flutter for Android and iOS
- Backend: NestJS, Node.js and TypeScript
- Database: PostgreSQL with Prisma ORM
- Architecture: Modular monolith with a versioned REST API

## Development status

Initial repository setup. Application implementation has not started.

## Security

- Never commit credentials, secrets or patient data.
- Use synthetic patient data during development and testing.
- Keep clinical documents private.
